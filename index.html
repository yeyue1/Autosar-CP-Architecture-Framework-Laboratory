SCOPE & SOURCES

你正在运行什么？

本工具是零依赖、确定性的离散事件教学模型。参考视频的 7 阶段 / 42 步和四大观测视图，启动 API 与解释以 AUTOSAR Classic R24-11 EcuM Flexible 为基线。步骤分组、任务周期、报文、时长和错误策略属于本项目示例配置，并不是 AUTOSAR 规定的唯一实现。

它不执行 AUTOSAR C 源码、不仿真 CPU 指令、不生成 ARXML / RTE，也不连接物理 CAN。STARTUP I / II 和 RUN 是方便与视频对照的教学阶段标签；不是声称现代 Flexible 内置了旧版 Fixed 的完整 RUN / POST-RUN 状态机。
